# 牛马日记（第三版优化方案）

## 1. 应用背景

**应用名称**：牛马日记  
**核心功能**：解决月底计算工时与加班时长的麻烦，提供可视化考勤管理与月度工时统计。  
**目标平台**：Android（原生 / Flutter / React Native 均可适配）  
**数据安全**：本地优先存储，支持云端备份与导出。

---

## 2. 应用架构

### 2.1 技术选型建议

| 层级 | 推荐方案 | 说明 |
|------|---------|------|
| **UI 层** | Jetpack Compose / Flutter | 日历组件自定义程度高，动画流畅 |
| **数据层** | Room (SQLite) + DataStore | 结构化存储考勤记录，键值对存储用户偏好 |
| **架构模式** | MVVM + Repository | 便于单元测试与状态管理 |
| **图表库** | MPAndroidChart / fl_chart | 用于月度统计可视化 |
| **导出功能** | Apache POI / csv | 导出 Excel/CSV 供 HR 或财务使用 |

### 2.2 数据实体设计

```kotlin
// 用户偏好表
@Entity(tableName = "user_preferences")
data class UserPreference(
    @PrimaryKey val id: Int = 1,
    val nickname: String = "牛马一号",
    val avatarUri: String? = null,
    val defaultWorkStart: String = "09:00",      // 默认上班时间
    val defaultWorkEnd: String = "18:00",        // 默认下班时间
    val defaultMidBreak: String = "12:00-14:00", // 中间休息
    val defaultNightBreak: String = "18:00-19:00", // 晚上休息
    val workDayColor: String = "#2196F3",        // 上班-蓝
    val restDayColor: String = "#4CAF50",        // 休息-绿
    val leaveDayColor: String = "#FFEB3B",       // 请假-黄
    val lateDayColor: String = "#F44336",          // 迟到-红
    val hourlyRate: Double? = null,              // 时薪（可选，用于薪资估算）
    val workWeekDays: String = "1,2,3,4,5"       // 默认工作日（周一到周五）
)

// 每日考勤记录表
@Entity(tableName = "daily_records")
data class DailyRecord(
    @PrimaryKey val date: String,           // 格式：yyyy-MM-dd
    val status: String,                     // WORK / REST / LEAVE
    val isFullDayOvertime: Boolean = false,
    val plannedStart: String? = null,       // 计划上班时间
    val actualStart: String? = null,        // 实际上班时间
    val plannedEnd: String? = null,         // 计划下班时间
    val actualEnd: String? = null,          // 实际下班时间
    val midBreakMinutes: Int = 120,         // 中间休息分钟数
    val nightBreakMinutes: Int = 60,        // 晚上休息分钟数
    val leaveStart: String? = null,         // 请假开始时间（仅请假状态）
    val leaveEnd: String? = null,           // 请假结束时间
    val workHours: Double = 0.0,            // 当日工时（小时）
    val overtimeHours: Double = 0.0,        // 当日加班时长（小时）
    val isLate: Boolean = false,            // 是否迟到
    val remark: String? = null              // 备注
)
```

## 4. 考勤页面（优化版）

### 4.1 日历区域

日历占据页面大部分位置，每个日期显示当日状态与关键信息：

| 状态 | 标注颜色 | 显示内容 |
|------|---------|---------|
| **上班** | 蓝色（可自定义） | 日期下方显示 `8h+2h`（工时+加班） |
| **休息** | 绿色（可自定义） | 显示「休」或留空 |
| **请假** | 黄色（可自定义） | 显示「假」+ 请假时段 |
| **迟到** | 红色边框/角标 | 在上班状态基础上叠加红色迟到标记 |

**智能初始化规则（新增）**：
- 首次打开应用时，根据「设置」中的 `workWeekDays` 自动将周末标记为「休息」。
- 法定节假日可手动批量标记为「休息」（提供一键设置）。
- 已编辑过的日期不再被自动规则覆盖。

### 4.2 日期点击弹窗（交互优化）

点击日历中任意日期，弹出底部弹窗（BottomSheet），分三个区域：

#### 区域一：状态选择（顶部）
- **状态切换**：三选一 Tab（休息 / 上班 / 请假），默认根据智能规则预填。
- 若选「休息」，下方表单折叠隐藏，仅保留备注输入框。

#### 区域二：时间表单（中部，可折叠）

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 是否全天加班 | 关闭 | 开启后，隐藏「晚上休息时间」，当日全部计入加班 |
| 计划上班时间 | 取自设置 | 仅展示，不可编辑（作为参照） |
| 实际上班时间 | 与计划一致 | 支持快捷按钮「迟到 5/10/30 分钟」 |
| 计划下班时间 | 取自设置 | 仅展示，不可编辑 |
| 实际下班时间 | 与计划一致 | 支持快捷按钮「加班 1/2/3 小时」 |
| 中间休息时间 | 取自设置 | 可修改，单位：分钟 |
| 晚上休息时间 | 取自设置 | 全天加班时隐藏 |
| 请假时间段 | 空 | **仅请假状态显示**，支持多段添加 |

#### 区域三：操作栏（底部）
- **复制昨日设置**：一键将上一天的配置复制到当天（排除日期相关字段）。
- **保存并继续**：保存后自动切换到下一个日期（方便批量录入）。
- **保存**：保存并关闭弹窗。
- **备注**：可选填写当日备注。

### 4.3 工时计算公式（修正版）

> **第二版修正说明**：修正了原公式中的时间顺序错误，增加了请假扣减逻辑。

#### 普通工作日（非全天加班）

```
基础工时 = 计划下班时间 - 计划上班时间 - 中间休息时间
实际工时 = 实际下班时间 - 实际上班时间 - 中间休息时间 - 请假时段

// 实际工时以基础工时为上限，超出部分计入加班
if (实际工时 > 基础工时):
    工时 = 基础工时
    加班时长 = 实际工时 - 基础工时 - 晚上休息时间
else:
    工时 = 实际工时
    加班时长 = 0
```

#### 全天加班日

```
工时 = 0
加班时长 = 实际下班时间 - 实际上班时间 - 中间休息时间
```

#### 请假日

```
工时 = 计划下班时间 - 计划上班时间 - 中间休息时间 - 请假时长
加班时长 = 0（如需加班可切换为上班状态）
```

#### 迟到判定

```
实际上班时间 > 计划上班时间 → isLate = true
```
- 迟到不影响工时计算，仅在日历中以**红色边框/角标**提示。
- 连续迟到 3 天及以上时，在统计页弹出提醒。

### 4.4 日历下方统计卡片（增强版）

页面底部固定显示当月汇总卡片，支持**左右滑动切换月份**：

| 统计项 | 说明 |
|--------|------|
| 本月上班天数 | 状态为「上班」的天数 |
| 本月工时合计 | 所有上班日的 `工时` 累加（小时） |
| 本月加班时长 | 所有上班日的 `overtimeHours` 累加（小时） |
| 本月请假天数 | 状态为「请假」的天数 |
| 迟到次数 | `isLate = true` 的天数 |
| 平均日工时 | 工时合计 / 上班天数 |
| 预估月薪（新增） | 若设置时薪，则 `工时×时薪 + 加班时长×时薪×1.5`（可选倍数） |

## 5. 统计页面（新增）

提供可视化分析，帮助用户了解工作强度趋势。

### 5.1 月度趋势图

- **柱状图**：展示当月每日的工时与加班时长对比。
- **折线图**：展示当月累计工时与累计加班时长的变化趋势。
- **标记点**：迟到日期以红色标记。

### 5.2 周期对比

- 支持选择两个月份进行对比，显示：
  - 工时变化率
  - 加班时长变化率
  - 迟到次数变化

### 5.3 工作强度分析

- **连续上班天数预警**：若连续上班超过 6 天，提示「注意劳逸结合」。
- **加班占比**：加班时长占总工时的比例。
- **平均下班时间**：计算当月平均实际下班时间。

### 5.4 数据导出

- **导出当月**：生成 Excel/CSV，包含所有字段，方便提交给 HR。
- **导出全部**：导出所有历史记录。
- **分享功能**：生成图片格式的月度总结，可分享至社交媒体。

## 7. 非功能性需求（新增）

### 7.1 性能要求

- 日历滑动帧率 ≥ 55 FPS。
- 月度统计计算耗时 ≤ 100ms（1 万条记录内）。
- 应用冷启动时间 ≤ 1.5 秒。

### 7.2 兼容性

- 最低支持 Android 8.0（API 26）。
- 适配深色模式（跟随系统或独立设置）。
- 支持屏幕旋转（日历横向展示更多日期）。

### 7.3 安全与隐私

- 所有数据本地存储，不上传服务器（除非用户主动开启云备份）。
- 导出文件可设置密码保护（可选）。
- 生物识别解锁（指纹/人脸）可选开启。

## 8. 优化总结（第三版 vs 第二版）

| 优化项 | 第二版 | 第三版 |
|--------|--------|--------|
| **公式修正** | 存在时间顺序错误 | 修正逻辑，增加请假扣减 |
| **页面结构** | 2 个 Tab | 3 个 Tab（新增统计页） |
| **智能初始化** | 无 | 根据工作日设置自动标记周末 |
| **批量操作** | 无 | 支持复制昨日、批量标记休息 |
| **数据导出** | 无 | 支持 Excel/CSV/JSON/图片 |
| **薪资估算** | 无 | 支持时薪设置与预估月薪计算 |
| **迟到处理** | 仅标记红色 | 增加连续迟到预警、统计追踪 |
| **数据持久化** | 未提及 | 明确 Room + DataStore 方案 |
| **深色模式** | 未提及 | 明确支持 |
| **安全隐私** | 未提及 | 增加生物识别与密码保护 |
